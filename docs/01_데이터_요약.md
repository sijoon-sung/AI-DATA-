# 데이터 요약

작성일: 2026-10-06. 이 문서의 수치는 모두 `scripts/01_inventory.py`, `02_preprocess.py`, `02b_dedupe.py`, `03_data_summary.py`를 실행해 실제로 잰 값이다. 판단이 들어간 문장은 "판단:"으로 표시했다.

> **2026-10-11 주의:** 발언 수, 문단 수, 약지도 라벨 수는 발언자 파서 결함을 고치기 전의 값이다. 고친 뒤의 값(분석 대상 발언 3,354,377개, 문단 3,679,475개, 30자 이상 2,282,682개 등)은 README의 "현재 상태"에 있다. 회의록 건수와 중복 제거 결과는 바뀌지 않았다.

## 1. 원자료의 형태

- 연도별 zip 두 개(`2024_광역 회의록.zip`, `2025_광역 회의록.zip`)에 의회별 JSON이 18개씩 들어 있다. 압축을 풀면 각각 1.2GB, 1.7GB다.
- zip 안의 파일명은 CP949로 저장되어 있지만 UTF-8 표시가 없어서, 그대로 읽으면 이름이 깨진다. `src/load.py`에서 복원한다.
- 회의록 한 건의 필드는 다섯 개다: `MTG_DE`(회의일자), `RASMBLY_NM`(의회명), `MTGNM`(회의명), `MINTS_NM`(회의록명), `MINTS_HTML`(원문 HTML).
- 전남광주통합특별시의회 파일은 두 해 모두 비어 있다(2바이트). 분석 대상은 17개 의회다.
- 의회마다 회의록 웹 시스템이 달라서 HTML 형식이 7~8가지다. 발언자 표기는 두 가지로 나뉜다.
  - A형(13개 의회): `○위원장 홍길동 의석을 정돈하여…`처럼 ○ 뒤에 직함, 이름, 발언이 한 줄에 이어진다.
  - B형(광주, 인천, 전남, 전북): 발언자만 한 줄에 쓰고 다음 줄부터 발언이 나온다. 전남은 `의장 홍 길 동`처럼 이름 글자 사이에 공백이 있고, 광주와 전북은 `↘` 표시가 앞에 붙는다.

## 2. 발견한 품질 문제와 처리

| 문제 | 규모 | 처리 |
|---|---|---|
| HTML이 완전히 같은 중복 | 378건 (전남 2024년 213건, 2025년 134건, 제주 27건 등) | 첫 건만 남김 (`dup_of`) |
| HTML은 조금 다르지만 본문이 같은 사본 | 2,117건. 특히 2025년 파일 다수에 회의록이 두 벌씩 들어 있음 (강원 624→275, 서울 715→356, 경북 404→211, 울산 358→196, 인천 455→221) | 같은 의회, 같은 날짜 안에서 길이 비율 0.97 이상, 앞 5,000자와 뒤 2,000자 유사도 0.95 이상이면 긴 쪽만 남김 (`near_dup_of`) |
| 회의록명이 회의를 구별하지 못함 | 강원은 회의명이 모두 "기타", 경기 일부는 "제회"처럼 회기 번호가 빠짐 | 본문 머리말에서 위원회명, 회기, 차수를 추출 (위원회명 추출률은 대부분 0.93 이상, 경북 0.73~0.76) |
| 본문 앞에 메뉴와 목록 텍스트가 붙음 | 서울, 경남, 대구, 경북, 부산, 대전, 세종 | "일시" 줄(또는 날짜 줄)을 기준으로 회의록 머리말 시작을 찾고 그 앞을 버림 |

판단: 2번 문제를 처리하지 않으면 2025년 논의량이 2024년의 두 배처럼 보여 트렌드와 확산 분석이 모두 왜곡된다.

## 5. 만들어진 파일 (`data/processed/`)

| 파일 | 내용 |
|---|---|
| `docs.parquet` | 회의록 1건이 1행이다. 평문 전체(`text`), 머리말 정보(위원회명, 회기, 차수), 본문 범위(`body_start`, `body_end`), 중복 표시(`dup_of`, `near_dup_of`, `keep`)를 담는다 |
| `utterances.parquet` | 발언 1개가 1행이다. 직함, 이름, 의원 측 여부, 위치(`start`, `end`)를 담는다. `docs.text[start:end]`가 발언 원문이다 |
| `agenda.parquet` | 회의록별 안건 목록과 유형(조례안, 건의안, 결의안, 동의안 등) |
| `agenda_unique.parquet` | 의회별로 같은 제목의 안건을 하나로 합친 목록 |
| `summary_by_council.csv` | 3절 표의 원본 |
| `inventory*.csv`, `inventory_html_struct.json` | 원자료 목록 조사 결과 |

분석 대상은 항상 `docs.keep == True`인 회의록이다.
