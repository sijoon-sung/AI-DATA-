**구현하며 데이터에서 새로 확인한 것**
- 재순위 모델의 점수는 "이 문단이 이 이슈를 중심으로 다루는가"에 가깝다. 짧은 대화체 언급("K패스가 5월부터 진행되고 있는데…")에도 0에 가까운 점수를 준다. 그래서 문단 단위 거르기에 쓰지 않고, 넓은 별칭이 끌어온 동명이의를 거르는 데와 "확인된 최초 관측"에만 쓴다.
- NLI 판정기는 전제가 길면 거의 모두 '중립'으로 판정한다. 지명 앞뒤 300자를 전제로 넣으면 참조 후보 94개 중 2개만 함의 0.5를 넘었고, 한 문장만 넣으면 49개가 넘었다. 전제는 문장 단위로 잘라 넣는다.
- 예측 백테스트(2025-01, 2025-07 기준점): AUC 0.675, 0.711. 이슈 안에서 의회를 가리는 AUC는 0.574, 0.595다. 등급별 실측 빈도는 단조다(상 13.7%, 중 6.4%, 하 2.1%, 최하 1.2%).

## 1. 한 줄 정의

회의록 전체에서 **근거가 붙은 사건**을 빠짐없이 뽑아(추출), **코드로 세고 정렬해서**(집계), 그 결과를 **근거와 함께 말하는**(서술) 시스템이다. RAG가 아니라 전수 추출과 집계의 문제로 본다.

## 3. 전체 구조

```
[0 데이터 바로잡기]  발언자 경계·문단 ID·부산 안건 수정 → 02~06 재실행, 회기 달력 표
        │
[1 이슈 카드]        안건 제목(정규화+묶기) + 발언 전용 이슈 → 정의·제외 규칙·검증된 별칭
        │             (기준시점마다 고정)
[① 추출]             별칭 일치 + 임베딩 + (의회 × 회의일) 칸 → 질의-답변 묶음 판정
        │             → 언급 성격·참조·법령 태그 → 원문 위치 검사
[▣ 사건표]           근거 단위의 단일 진실 원천
        │
[② 집계]             최초(두 가지 + 구간 + 인증) · 흐름(참조/공통 법령/순서 세 축)
        │             · 이슈 유형 · 예측(이슈 단위 + 의회 집합)
[③ 서술·검증]        LLM은 자리표시자 문장만, 값은 코드가 채움, 문법·금지어 제약
        │             → 원문 일치·NLI·사건표 대조 → 기권
[출력]               대회 결과표, JSON 이슈 카드, 흐름도, 누출 감사표, 데모
```

**네 가지 원칙**
1. 사건표에 없는 사실은 말하지 않는다. 모든 행은 원문 위치를 가진다.
2. 추출은 넓게 찾고 정확히 판정한다.
3. 세기, 정렬, 최솟값, 확률은 코드와 통계 모형이 한다.
4. LLM은 애매한 판정의 보조와 서술만 하고, 서술은 검사를 통과한 것만 내보낸다.

## 4. 단계별 설계

### 0. 데이터 바로잡기와 준비

- **발언자 경계:** `src/segment.py`의 발언자 패턴이 놓치는 표기를 고친다.
  - 전북: 이름과 직함이 붙은 줄
  - 부산: 두 단어 직함
  - 충남: 이름을 띄어 쓴 경우
  - 영문이 섞인 직함, '자'로 끝나는 직함(후보자 등)
  - 의회별 회귀 검사를 둔다: 의원 측 발언 비율 50~60%, 놓친 경계 뒤 글자 0.5% 미만.
- **문단 ID:** `(doc_id, start)`로 고정한다. 파서를 고쳐도 검수 라벨이 깨지지 않게 하기 위해서다. 검수 표본(06단계)은 이 뒤에 다시 만든다.
- **부산 안건:** 2025년 안건 추출을 점검한다.
- **회기 달력 표:** (의회, 회기, 회의일, 회의 종류)를 만든다. 관측 구간과 검색 칸의 기준이다.
- **색인:** bge-m3 임베딩은 30자 이상 문단만, 의회별로 나눠 디스크에 둔다.

### 1. 이슈 카드

| 필드 | 내용 |
|---|---|
| 이름, 층 | 정책 수단(아래층) / 주제(위층) |
| 출처 | 안건 제목 / 발언 전용 |
| 정의와 제외 규칙 | 예: 티메프는 2024-07 정산 사태 이후만, 딥페이크는 성범죄 맥락만 |
| 검증된 별칭 | 기준시점 이전 코퍼스에 실제로 나오는 표기만 |
| 대표 조례 | 안건 제목에서 |
| 기준시점 | 이 카드가 고정된 시점 |

- **제목에서 오는 이슈:** 지역명과 개정 꼬리를 지운 뒤(L1), 기능어를 빼고 어순을 무시한다(L2·L3). 이렇게 하면 3곳 이상 의회에 나오는 수단이 613개에서 679개로 는다. 그 다음 임베딩으로 묶고, 묶은 쌍의 정밀도를 표본으로 확인한다. 건의안과 결의안도 넣는다.
- **발언 전용 이슈:** 정책 고유명사 후보를 접미어 규칙(-카드, -패스, -학교, -수당, -기본소득 등)과 급증 탐지로 찾고, 사람이 확인한다.
- **별칭:** LLM이 제안하고, 기준시점 이전 코퍼스에 나오는 것만 받는다. 이 검증이 미래 정보 누출도 함께 막는다.

| 단계 | 하는 일 | 쓰는 것 |

### ② 집계: 사건표 → 이슈별 사실

**최초 관측** (이슈, 의회마다)
- "최초 언급"과 "최초 실질 논의"를 함께 낸다. 첫 언급의 44.8%가 그 회의에서 한 번만 나온 말이기 때문이다.
- 상정일과 의결일도 낸다.
- 관측 구간은 회기 기준으로 정한다: (직전에 언급이 없던 회기, 첫 언급].
- 확실성 인증을 붙인다(상향안 U1).
- 좌측 절단 표시를 붙인다. 관찰 준비 기간에 이미 있었거나, 기간 밖 선례를 말한 발언이 있는 경우다.

**흐름: 세 축을 섞지 않는다**

| 축 | 언제 | 그림 | 허용하는 말 |
|---|---|---|---|
| 참조 (E1) | B가 A의 정책을 사례로 말한 근거 구간이 있다 | A → B 화살표 | "A의 사례를 언급하며" |
| 공통 법령 (E2) | 두 의회가 같은 특정 법령을 인용한다(지방자치법 같은 일반 법령은 뺀다) | 법령 노드에서 두 의회로 | "같은 법령(○○법)에 대응해" |
| 순서 (E3/E4) | 관측 구간이 회기 기준으로 겹치지 않으면 E3, 겹치면 E4 | 화살표 없는 타임라인 | "이후 관측됨" / 순서를 말하지 않음 |

**이슈 유형** (텍스트 증거 우선)
- 법 대응형: 같은 특정 법령과 촉발 표현이 있다.
- 참조 확산형: E1이 있다.
- 근거 미확인 다지역형: 기본값이다. 시험 적용에서 77%가 여기에 든다.
- 단일 지역형

몰림 검정과 달력을 보정한 선행표는 판정기로 쓰지 않는다. "순서는 대부분 달력"이라는 결과를 보여 주는 그림으로 쓴다.

**예측** (J2)
- **주어:** 이슈. 다음 6개월에 더 퍼질 가능성과 예상 신규 의회 수를 낸다.
- **의회:** 놓침률을 보장하는 의회 집합(분할 등각 위험 통제)과 등급으로 낸다.
- **모형:** 6개월 직접 예측 로지스틱(월별 기준점 누적 학습). 2024년 상반기 기준시점과 민감도 분석에는 월 단위 위험 모형을 쓴다.
- **위험 집합:** 기간 안 첫 안건이 개정·폐지인 의회는 이미 조례가 있으므로 뺀다.
- **변수:** 채택 비율, 최근 채택 수, 경과 기간(상한 둠), E1 전조 신호(태그가 나온 뒤), 이슈 유형. 회의 노출 변수는 효과가 0이라 뺀다.
- **보정과 등급:**
  - 직전 창의 절편 이동으로 보정한다.
  - 등급 경계는 기저율의 5배·2배·0.5배로 미리 정한다.
  - 간이 실험(T2+T3 합산)에서 등급별 실측 빈도는 단조였다: 상 7.42%, 중 4.44%, 하 1.34%, 최하 0.61%.
- **누출 감사:** 미래 정보를 일부러 넣은 카나리아 실험을 한다. "결국 퍼진 이슈만" 고르면 기저율이 1.27%에서 7.51%로 부푼다는 것을 보여 준다. 입력 스냅샷 해시와 요인별 근거를 담은 예측 영수증을 남기고, 최종 예측은 해시로 사전 등록한다.

### ③ 서술과 검증

- **자리표시자 생성:** Qwen은 `{의회A}`, `{날짜A}`, `{인용1}` 같은 자리표시자로 된 문장 틀만 쓴다. 값 치환과 조사 맞춤(은/는, 이/가)은 코드가 한다. 그래서 날짜, 의회, 인용의 환각이 구조적으로 생기지 않는다.
- **말의 세기:** S0~S6 척도를 두고 근거 등급별 상한을 정한다. E1 → S3, E2 → S2, E3 → S1, E4 → S0이다.
- **제약 디코딩:** 주장마다 만든 문법(GBNF)으로 숫자, 지명, 따옴표를 막고, 금지 표현 자동자(Aho–Corasick)를 직접 만든 탐욕 디코딩 루프에 넣는다(상향안 U4).
- **세 가지 검사:**
  1. 원문 일치
  2. NLI: 가설은 "발언자는 ~라고 말한다"는 귀속형으로 세운다.
  3. 사건표 대조: 날짜, 의회, 순서, '최초'에 '관측' 한정어가 붙었는가, 세기 상한, 인용 일자 ≤ 기준시점
  - 인과 과장 검사는 시스템이 쓴 문장에만 한다. 인용 원문의 20%에 이미 인과어가 있기 때문이다.
- **기권 기준:** NLI 점수 임계값은 등각 방법으로 정해, 근거 없는 주장의 비율을 목표 위험 이하로 보장한다.
- **실패 처리:** 재생성 2회 → 템플릿 → "확인할 수 없음"으로 기권한다.
- **오류 주입 시험:** 가짜 인용, 날짜 이동, 의회 바꿔치기, 순서 뒤집기, 거짓 "최초" 등 11가지를 심는다. 순서 뒤집기와 거짓 최초는 NLI가 구조적으로 잡지 못하므로 사건표 대조가 필수임을 보인다.
- **실행 환경:** Qwen2.5-7B Q4_K_M GGUF(4.68GB)를 llama.cpp로 돌린다. Windows용 CUDA 휠이 있다.

## 5. 기술 난이도 상향안

기본안 위에 다섯 개를 얹는다. 각 상향안은 연구문제나 심사 기준 하나를 직접 책임진다.

| | 상향안 | 하는 일 | 책임지는 곳 | 공수 |
|---|---|---|---|---|
| U1 | **인증된 최초 관측** | 경계 이전 후보를 층화 표집하고, 초기하 검정과 두 경로(키워드·임베딩) 포획-재포획으로 놓친 이른 언급의 가능성에 상한을 둔다. 지금의 "3/n" 감사는 경계 이전 문단이 중앙값 8,386개라서 실질 보장이 되지 않는다 | RQ1, J1 최초 | 3일 (축소판 1.5) |
| U2 | **근거 구간 참조 관계 추출** | (참조 의회, 대상 정책, 태도, 근거 구간)을 뽑는다. KoELECTRA로 분류하고, Qwen이 정책 구간을 제안하면 코드가 원문과 대조한다. 임계값은 F0.5로 정한다. 안건 구조를 약한 감독으로 쓴 발언 → 정책 수단 연결도 포함한다 | J1 경로, J2 전조 신호 | 4일 |
| U3 | **코퍼스로 검증한 별칭 확장** | LLM이 별칭을 제안하고, 기준시점 이전 코퍼스에 나오는 것만 받는다 | J1 재현율, 누출 차단 | 2~2.5일 |
| U4 | **제약 디코딩과 등각 기권** | 자리표시자 문법, 금지 표현 자동자, 직접 만든 디코딩 루프, Neyman–Pearson식 기권 임계값 | RQ2, 규정(인과 단정 금지) | 3.5일 |
| U5 | **누출 감사와 의회 집합 보장** | 카나리아 실험, 예측 영수증, 해시 사전 등록, 분할 등각 의회 집합 | J2 | 2일 |

**조건부 (조건이 맞을 때만 한다)**
- LLM → KoELECTRA 증류와 능동학습(4일): Qwen이 사람 라벨 500건과 κ ≥ 0.6일 때.
- 코퍼스 안 법령 정규화와 인용 기능 분류(2.5일): E2가 결과표에서 중요해질 때.
- 한국어 인과 세기 분류기(2일): 금지어 자동자만으로 부족할 때.
- 임베딩 대조 미세조정(3일): 묶은 쌍의 정밀도가 0.90 미만일 때.

**하지 않는 것**
- Qwen QLoRA 미세조정: 8GB GPU와 여유 메모리 2GB에서 위험하고, U4로 이미 과장이 막혀 이득이 작다.
- NetInf·Hawkes 선행망 추정: 데이터로 식별할 수 없다.
- 몰림 검정을 유형 판정기로 쓰는 것: 검정력이 없다.
- 회의 노출 변수, 부스팅 주 모형: 이득이 0이거나 음수였다.

## 6. 연구문제

**RQ1. 집계형 질문("언제 처음 / 어디어디·몇 곳 / 누가 먼저")에서 RAG와 키워드 집계는 얼마나 틀리고, 근거 단위 추출-집계는 얼마나 정확한가?**
- 비교 대상:

  | 방식 | 설명 |
  |---|---|
  | RAG | 상위 k개(5/10/20)를 검색하고 LLM이 답한다 |
  | 키워드 집계 | 공식 명칭 그대로 센다 |
  | 우리 | 별칭 + 회의일 칸 + 묶음 판정 + U1 |

- 지표:
  - 최초 날짜 오차(늦게 잡은 경우와 이르게 잡은 경우를 따로)
  - 의회 목록의 정밀도와 재현율
  - 순서 일치도(Kendall τ)
  - 인증 포함률
- 평가 이슈:
  - A층: 고유한 이름의 이슈 15~30개. 정규식 전수 검색으로 참값에 가깝게 얻고 사람이 확인한다.
  - B층: 일반 이슈 표본.
- 현재 대리 실험 결과: 상위 10개 RAG는 최초를 34~44%만 찾고, 큰 이슈에서는 8~13%다. bge-m3로 다시 잰다.

**RQ2. 말의 세기를 근거 등급에 묶으면 인과 과장이 얼마나 줄어드는가?**
- 비교 대상:
  1. 일반 RAG 서술
  2. 허용 표현 지시
  3. 자리표시자와 제약 디코딩(U4)
  4. 3에 검사와 기권을 더한 것
- 지표: 인과 과장률(등급별), 근거 없는 주장 비율, 기권률과 위험–적용범위 곡선
- 정답: 생성 주장 약 200개와 최소쌍 150개를 사람이 판정한다. 어느 방식이 만든 문장인지 가린 채로 한다.

**데이터 발견으로 보고할 것:** "확산 순서처럼 보이는 것의 대부분은 회기 달력"(r = 0.93)과 "예측력은 이슈 수준에서 나온다". 둘 다 연구문제는 아니지만 다른 접근이 놓치는 사실이다.
