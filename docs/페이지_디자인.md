# 프로젝트 소개 페이지 디자인 명세 (제품 사이트형)

작성일: 2026-10-06. 이 문서는 GitHub Pages에 올릴 한 장짜리 소개 사이트의 시각 설계와 동작 명세다. 문안의 원본은 `docs/페이지_기획.md`(P0~P13)이고, 이 문서는 그 문안을 어떤 모양과 움직임으로 보여 줄지를 정한다. 개발자는 이 문서만 보고 HTML, CSS, 바닐라 JS로 구현할 수 있어야 한다.

**표기 약속**
- 크기는 모두 CSS px이다. 색은 HEX로 적고, 구현에서는 3장의 CSS 변수 이름으로 쓴다.
- `[제품명]`은 제품명 자리표시자다. 크기 계산은 기획 문서의 추천안인 "광역의회 정책 이슈 확산 분석 시스템"(17자)을 기준으로 했다.
- "데스크톱"은 1280px 화면을, "모바일"은 375px 화면을 기준으로 수치를 적었다. 그 사이 폭에서의 규칙은 3.7절과 9장에 있다.
- 와이어프레임 안의 괄호 숫자 `(24)`는 위아래 요소 사이의 세로 간격(px)이다.

## 1. 디자인 방향

1. 이 사이트는 아직 결과가 없는 시스템을 소개하므로, 화려한 장식 대신 **이 시스템의 표기 규칙 자체**(실선은 명시적 참조, 점선은 시간 선후, 채움은 관측, 테두리만은 예측)를 시각 정체성으로 삼는다.
2. 첫 화면은 깊은 남색 위의 한국 타일 지도와 굵기 대비가 큰 한글 헤드라인으로 제품 사이트의 인상을 만들고, 본문은 흰색과 옅은 회색 구역을 번갈아 써서 표와 수치를 편하게 읽게 한다.
3. 색은 남색(신뢰, 기록), 주황(관측과 주목), 하늘색(예측과 링크) 세 가지만 의미를 가지고 쓴다. 나머지는 모두 무채색이다.
4. 움직임은 의미가 있을 때만 쓴다. 지도 애니메이션은 "어떤 순서로, 어떤 근거로 이어졌는가"를, 막대 애니메이션은 "처리 전과 처리 후"를 보여 준다.
5. 숫자는 모두 실측값이고, 예시와 도식에는 점선 테두리 표지를 붙여 실제 결과와 섞이지 않게 한다. 심사위원이 오해할 여지를 남기지 않는 것이 이 디자인에서 가장 우선하는 기준이다.

## 2. 시각 정체성

### 2.1 워드마크와 로고마크

**로고마크 (24×24)**: 둥근 사각 타일 두 개를 "먼저 내려가고 옆으로 이어지는" 꺾인 선으로 잇는다. 타일 지도와 근거 연결선을 줄인 모양이다.

```html
<svg class="mark" viewBox="0 0 24 24" width="24" height="24" aria-hidden="true">
  <rect x="2"  y="13" width="9" height="9" rx="2" fill="currentColor"/>
  <rect x="13" y="2"  width="9" height="9" rx="2" fill="#FF8A3D"/>
  <path d="M6.5 13 V8.5 Q6.5 6.5 8.5 6.5 H11" fill="none" stroke="#FF8A3D" stroke-width="2"/>
</svg>
```
- 왼쪽 아래 타일은 `currentColor`라서, 어두운 바탕에서는 흰색(#F4F6FA), 밝은 바탕에서는 남색(#0B1324)이 된다.
- 주황 #FF8A3D는 바탕과 상관없이 고정한다.

**워드마크 조합 (로고마크 + 이름)**

| 변형 | 쓰는 곳 | 마크 | 이름 글자 | 간격 |
|---|---|---|---|---|
| 두 줄형 (기본) | 내비게이션 | 24px | 14px / 700 / 행간 18px / 자간 −0.02em, 두 줄 | 마크와 글자 사이 10px |
| 두 줄형 (큼) | 푸터 | 32px | 18px / 700 / 행간 24px / 자간 −0.02em, 두 줄. 그 아래 영문명 13px / 500 / `--fg-3` | 12px |
| 한 줄형 | 이름이 10자 이하로 확정될 때만 | 24px | 17px / 800 / 자간 −0.03em | 10px |

- 두 줄형의 줄바꿈 위치는 의미 단위로 고정한다. 예: "광역의회 정책 이슈 / 확산 분석 시스템". 줄바꿈은 `<br>`로 넣고 `aria-label`에 이름 전체를 넣는다.
- 영문명(Council Issue Diffusion Analyzer)은 내비게이션에 쓰지 않는다. 푸터와 `<title>`, OG 메타에만 쓴다.
- 여백: 마크 높이의 절반 이상을 사방에 비운다.
- 금지: 그라데이션, 외곽선 글자, 기울이기, 그림자, 마크만 따로 색 바꾸기.
- 파비콘: 32×32 남색(#0B1324) 바탕, 모서리 6px, 가운데에 마크 20px(왼쪽 아래 타일은 #F4F6FA).

### 2.2 한 가지 시각 문법 (페이지 전체에 똑같이 적용)

| 모양 | 뜻 | 쓰는 곳 |
|---|---|---|
| 주황으로 **채운** 타일·점·막대 | 관측됨, 또는 지금 주목할 값 | 히어로 지도, 레인 도식, 처리 후 막대 |
| **테두리만** 있는 타일·원 (하늘색) | 아직 관측되지 않음, 예측 대상 | 히어로 5단계, 기능 3 도식 |
| **실선 + 화살촉** (흰색 또는 남색) | 명시적 참조 | 지도, 레인, 근거 수준 표, 결과표 |
| **점선, 화살촉 없음** (회색) | 시간 선후만 확인됨 | 같은 곳 |
| 선 없이 함께 채워진 타일과 옅은 띠 | 공통 외부요인형, 경로를 그리지 않음 | 지도 시나리오 2, 레인 도식 |
| **점선 테두리** 꼬리표 | 예시·도식·가정 (실제 결과 아님) | 예시 시나리오, 도식, 형식 예시 |
| 채운 원 / 반만 채운 원 / 빈 원 | 완료 / 진행 / 계획 | 상태 표시 전체 |

화살표 모양 하나, 점선 하나도 이 표 밖의 뜻으로 쓰지 않는다. 예를 들어 장식용 점선 구분선은 쓰지 않는다.

### 2.3 쓰지 않는 것

보라·파랑 그라데이션, 그라데이션 글자, 글래스모피즘과 배경 블러, 떠다니는 블롭, 네온 글로우, 이모지, 장식용 아이콘(기능적 아이콘은 GitHub 마크, 메뉴, 닫기, 일시정지/재생, 펼침 화살표, 바깥 링크 화살표만 허용), 아이콘+제목+설명 카드 3열 반복, 일러스트, 영어 마케팅 문구, 패럴랙스, 스크롤 가로채기, 마우스를 따라다니는 효과, 큰 그림자, 12px보다 큰 모서리 둥글기(알약형 꼬리표 제외).

### 3.3 다크 모드 (`prefers-color-scheme: dark`)

- 어두운 구역(hero, P5, P7, P12)은 그대로 둔다. 다만 밝은 구역이 어두워지면 구분이 사라지므로, 다크 모드에서는 어두운 구역 `--bg`를 #070D1A로, `--card`를 #0B1324로 한 단계 내린다.
- 밝은 구역은 아래처럼 바꾼다. 구역 교차(흰색/회색)는 #0E1729/#111C31의 교차로 유지한다.

| 변수 | light → 다크 모드 | light-alt → 다크 모드 |
|---|---|---|
| `--bg` | #0E1729 | #111C31 |
| `--card` | #142038 | #142038 |
| `--card-sub` | #1A2741 | #1A2741 |
| `--fg-1` / `--fg-2` / `--fg-3` | #F4F6FA / #B7C1D3 / #8A96AC | 같음 |
| `--line` / `--line-2` | #22304D / #2E3E5E | 같음 |
| `--eyebrow` / `--link` / `--focus` | #FF8A3D / #7CC4FA / #7CC4FA | 같음 |
| `--btn-primary-*` | 어두운 구역 값과 같음 | 같음 |
| 데이터 시각화 변수 | 3.4절 dark 열 값 (단 `--viz-context`는 #66758F) | 같음 |

- 구현: `:root`에 `color-scheme: light dark`. 위 매핑은 `@media (prefers-color-scheme: dark) { [data-surface="light"] {…} }`로 넣는다. 수동 전환 버튼은 두지 않는다.
- 그림자와 이미지가 없으므로 그 밖에 바꿀 것은 없다. 차트는 변수만 쓰므로 자동으로 바뀐다.

### 3.9 모션 토큰과 원칙

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--ease-out` | cubic-bezier(0.22, 0.61, 0.36, 1) | 진입, 막대 성장, 타일 채움 |
| `--ease-in-out` | cubic-bezier(0.65, 0, 0.35, 1) | 선 그리기, 상태 전환 |
| `--ease-standard` | cubic-bezier(0.4, 0, 0.2, 1) | hover, 접힘 |
| `--dur-1` | 120ms | hover 색 변화 |
| `--dur-2` | 200ms | 내비게이션 상태, 탭 전환 |
| `--dur-3` | 360ms | 타일 채움, 패널 내용 전환 |
| `--dur-4` | 560ms | 스크롤 진입 |
| `--dur-5` | 800ms | 차트 형태 변화 |

- **스크롤 진입**: `[data-reveal]` 요소는 처음에 `opacity:0; transform:translateY(12px)`(큰 차트 카드는 16px)이고, 화면에 15% 들어오면(`IntersectionObserver`, `threshold: 0.15`, `rootMargin: "0px 0px -10% 0px"`) `opacity:1; transform:none`이 된다. 시간은 `--dur-4`, 곡선은 `--ease-out`이다. 같은 묶음의 자식은 80ms씩 늦추며 최대 6개까지만 늦춘다. 한 번만 실행한다.
- 움직이는 속성은 `opacity`, `transform`, SVG `stroke-dashoffset`뿐이다. 막대 성장은 `transform: scaleX/scaleY`(`transform-box: fill-box`, 기준점은 막대의 시작점)로 한다.
- 패럴랙스, 스크롤 연동 확대, 1.02배를 넘는 hover 확대는 쓰지 않는다.
- **움직임 줄이기**(`prefers-reduced-motion: reduce`): 진입 효과 없이 처음부터 보이게 한다. 카운트업은 최종값만 보인다. 차트는 최종 상태로 그린다. 히어로는 정지 화면이다(7.1절). 탭 내용 전환과 접힘은 즉시 바꾼다.
- **JS가 없을 때**: 진입 효과용 클래스는 JS가 `<html class="js">`를 붙인 뒤에만 적용한다. HTML에는 최종 숫자와 최종 문안을 그대로 둔다.

## 7. 차트와 다이어그램 명세

### 7.0 공통 골격 (모든 SVG 차트)

- **폭에 맞춰 다시 그린다.** SVG 안 글자가 화면 폭에 따라 줄어들지 않도록 `viewBox`를 늘리지 않는다. 대신 차트마다 `render(container, data)` 함수를 두고, `W = container.clientWidth`로 좌표를 계산해 `<svg width=W height=H viewBox="0 0 W H">`를 만든다. SVG 1단위는 화면 1px이다.
- `ResizeObserver`로 폭이 1px 넘게 바뀌면 100ms 뒤에 다시 그린다. 다시 그릴 때는 애니메이션 없이 최종 상태로 그린다.
- 컨테이너에는 `min-height: H`를 미리 줘서 그리기 전후로 레이아웃이 밀리지 않게 한다(CLS).
- 글자: `font-family: inherit`, 축과 라벨은 12~13px, `font-variant-numeric: tabular-nums`. 글자색은 `--fg-1/2/3`만 쓴다. 계열 색을 글자에 쓰지 않는다.
- 선 위에 글자가 겹칠 수 있는 곳(주석, 레인 라벨)은 글자에 바탕색 테두리를 준다: `paint-order: stroke; stroke: var(--card); stroke-width: 4px; stroke-linejoin: round`.
- 눈금선 1px `--viz-grid` 실선, 기준선 1px `--viz-axis`. 점선 눈금선은 쓰지 않는다(점선은 "시간 선후" 전용).
- 막대: 두께 최대 24px. 값 쪽 끝만 모서리 3px, 기준선 쪽은 직각(`path`로 그림). 붙어 있는 막대 조각 사이는 2px 바탕색 간격.
- 접근성: `<svg role="img" aria-labelledby="제목id 설명id">` 안에 `<title>`과 `<desc>`(핵심 수치를 문장으로)를 둔다. 같은 값을 HTML 표나 문장으로도 제공한다.
- 진입 애니메이션: 차트 컨테이너가 30% 보일 때 한 번 실행한다. 움직임 줄이기에서는 최종 상태로 그린다.

**연결선**
- 중심점에서 중심점으로 잇는 2차 베지어 곡선. A=출발 중심, B=도착 중심, d=B−A, L=|d|. 법선 n은 (−d.y, d.x)/L와 그 반대 가운데 **n.y > 0**인 쪽(가로선은 아래로 휨), n.y = 0이면 **n.x > 0**인 쪽(세로선은 오른쪽으로 휨)을 고른다. 지역명이 왼쪽 위에 있어서 선이 이름을 가리지 않게 하기 위해서다. 제어점 C = (A+B)/2 + n·0.18L.
- 시작은 A에서 8px, 끝은 B에서 12px 떨어뜨린다(접선 방향으로 자름).
- 명시적 참조: 2px #F4F6FA 실선 + 화살촉. 화살촉은 `<marker markerUnits="userSpaceOnUse" markerWidth="8" markerHeight="8" refX="8" refY="4" orient="auto">`, 경로 `M0 0 L8 4 L0 8 Z`, 채움 #F4F6FA.

선은 모두 이웃한 타일 사이이므로 다른 타일을 지나지 않는다(세종(1,1)에서 충남(1,0), 충북(1,2), 대전(2,1)).

**시나리오 2: 공통 외부요인형**: 서울, 부산, 인천, 경기, 강원, 전남, 경북, 경남, 제주 9개 타일이 거의 동시에 관측됨으로 바뀐다. 번호 표지와 선은 없다. 캡션은 기획 문안 그대로다.

- 연결선은 **먼저 내려가고 옆으로 가는 꺾은선**이다. 출발 점에서 바로 아래로 내려가 도착 레인 높이에서 둥글게 꺾여(반지름 6) 오른쪽으로 간다.

  - 가로 구간의 길이가 곧 관측 간격이 된다. 레인 순서가 관측 순서이므로 세로 구간은 다른 점을 지나지 않는다.
  - 명시적 참조: 2px `--viz-ref` + 화살촉(7.1절 marker, 채움 `--viz-ref`). 시간 선후: 1.5px `--viz-time`, `stroke-dasharray="5 4"`, 화살촉 없음.
- 점 오른쪽 주석: 점에서 10px 오른쪽, 기준선 y+4, 12px / 500 `--fg-2`, 바탕색 테두리(7.0절).

**유형별 데이터**

| 탭 | 관측 점 (레인: 월) | 연결 | 주석 |

| 순차 확산형 | A:2, B:4, C:6, D:8, E:9 | A→B 실선, A→C 실선, C→D 점선, C→E 점선 | A "최초 관측", B·C "A 언급", D·E "참조 없음" |

**전환**: 탭을 바꾸면 기존 점과 선이 `opacity 1→0` 160ms, 새 점이 레인 순서대로 60ms씩 늦춰 `opacity`와 `scale 0.6→1` 240ms로 나타난다. 이어서 연결선이 100ms씩 늦춰 500ms `--ease-in-out`로 그려진다(실선은 dashoffset, 점선은 마스크). 처음 화면에 들어올 때도 같은 순서로 그린다.

**P4 기능 2 축소판**: 레인 3개(A, B, C), A:2, B:5, C:8, A→B 실선, B→C 점선. 탭과 주석은 없고, 범례 한 줄(글리프 2개)을 아래에 둔다. 높이 170. 배치 공식은 같다.
- 주의: 한 점에서 나가는 실선과 점선은 세로 구간을 같이 쓰게 되어 겹쳐 보인다. 그래서 한 점에서는 같은 종류의 선만 나가게 예시 데이터를 짰다(본 도식도 A에서는 실선 둘, C에서는 점선 둘). 실제 결과를 그릴 때 한 점에서 두 종류가 나가면 점선의 세로 구간을 x + 4로 옮긴다.

### 7.9 지표 카운트업 (P2)

- HTML에는 최종값을 그대로 쓴다. JS는 지표 띠가 화면 아래에 있을 때만 시작 전에 0으로 바꿔 두고, 띠가 40% 보이면 한 번 센다.
- 시간 1,400ms, 곡선 easeOutCubic(`1 − (1 − t)^3`), 항목마다 120ms 늦춤. 매 프레임 `Math.round(v)`를 `toLocaleString('ko-KR')`로 찍는다.
- "4억 1,600만"은 만 단위 정수(0 → 41,600)를 세어 `억 = Math.floor(v/10000)`, `만 = v % 10000`으로 나눠 찍는다. 억이 0이면 억 부분을 숨긴다.
- 숫자가 바뀌는 `<span>`에는 `aria-hidden="true"`를 붙이고, 옆에 시각적으로 숨긴 최종값 문장(예: "분석 대상 광역의회 17개")을 둔다.
- 움직임 줄이기: 세지 않는다.

- [ ] `<html lang="ko">`, 영문 모델명은 `mono` 칩 안에서 `lang="en"`
- [ ] 첫 초점 요소는 "본문 바로가기" 건너뛰기 링크

- [ ] 히어로 애니메이션: 일시정지 버튼, 화면 밖과 숨김 탭에서 자동 정지, 움직임 줄이기에서 정지 화면

## 10. 인쇄 스타일 (`@media print`)

심사위원이 인쇄해서 읽을 수 있으므로 별도 규칙을 둔다.

- `@page { size: A4; margin: 16mm 14mm 18mm; }`
- 모든 구역을 밝은 구역 토큰으로 바꾼다. 어두운 구역(히어로, P5, P7, P12, 푸터)도 바탕 #FFFFFF, 글자 #0B1324, 선 #CBD3DF. 주황 버튼과 꼬리표는 테두리 1px #0B1324 + 글자로 바꾼다.
- 숨김: 내비게이션, 메뉴, 일시정지 버튼, 탭 단추, 건너뛰기 링크, 표 스크롤 안내 문장.
- 히어로: `min-height` 해제. 지도는 움직임 줄이기 장면(시나리오 1 마지막 장면)으로 그리고, 캡션 5개 목록을 인쇄한다. 타일은 빈 타일 #F4F6F9 + 테두리 #CBD3DF, 관측 타일 #DD5C0E + 글자 #0B1324, 연결선 #0B1324로 바꾼다.
- 작동 방식: 아코디언과 탭을 풀고 8개 단계를 모두 펼친 목록으로 인쇄한다(CSS로 모든 패널 표시).
- P7 레인 도식: 세 유형을 세로로 모두 인쇄한다.
- `<details>`는 모두 펼친다. 인쇄 직전 `beforeprint` 이벤트에서 `open`을 붙이고 `afterprint`에서 되돌린다.
- 차트: 애니메이션 없이 최종 상태. `print-color-adjust: exact`를 차트와 상태 모양에 준다. 흑백 인쇄에서도 구분되도록 처리 전 막대는 `--viz-context` 대신 #BDC4D0으로 밝게 한다(주황 막대와의 명도 차이를 키움).
- 바깥 링크 뒤에 주소를 붙인다: `a[href^="http"]::after { content: " (" attr(href) ")"; font-size: 9pt; }`. 문서 목록과 저장소 링크에 해당한다.
- 쪽 나눔: `h2, h3 { break-after: avoid; }`, 카드, 표 행, 타임라인 항목, 주석 상자에 `break-inside: avoid`. 각 구역(`section`)은 새 쪽에서 시작하지 않는다(종이 절약).
- 글자: 본문 10.5pt / 1.6, h2 18pt, h3 13pt, 표 9pt.

## 11. 구현 메모

**파일 구조** (GitHub Pages, 빌드 도구 없음)
```
site/  (또는 docs/site/, 게시 위치는 개발자가 정함)
  index.html
  assets/css/site.css        토큰 → 기본 → 컴포넌트 → 섹션 → 인쇄 순서

  assets/img/favicon.svg, og.png (1200×630)
```

**JS 모듈** (전체 목표 30KB 이하, 라이브러리 없음)
1. `nav`: 배경 상태, 현재 섹션 표시, 모바일 메뉴
2. `reveal`: 스크롤 진입
3. `countUp`: 지표 띠
4. `heroMap`: 타일 지도, 시간표, 탭, 일시정지

6. `steps`: 작동 방식 탭/아코디언
7. `tabs`: 공용 탭 동작(키보드)
8. `sortTable`: 의회별 규모 표
9. `timeline`: 로드맵 상태 집계와 오늘 표시
10. `print`: beforeprint/afterprint에서 details 펼치기

**성능 목표**: Lighthouse 성능 90 이상, 접근성 95 이상, CLS 0.05 미만. 글꼴은 두 종류만 불러온다. 지도와 차트는 화면에 들어오기 전에는 그리지 않는다(히어로 지도만 즉시).

**OG 이미지 (og.png, 1200×630)**: 바탕 #0B1324, 왼쪽에 워드마크(두 줄형 큼, 글자 40px)와 헤드라인(52px, 300/800 대비), 오른쪽에 시나리오 1 마지막 장면의 타일 지도(타일 72). 오른쪽 아래에 "예시 시나리오" 꼬리표를 넣는다. 페이지를 띄워 같은 크기로 캡처해 만든다.

**데이터와 규정 주의 (기획 문서와 같은 원칙)**
- 페이지와 `page-data.json`에는 문서에 이미 공개된 집계 숫자만 넣는다. 회의록 원문, 발언자 이름, 회의록 화면 갈무리는 넣지 않는다(참가 서약의 제3자 열람·제공 금지).
- 예시와 도식에는 실제 날짜, 실제 수치를 쓰지 않는다. 히어로 지도만 실제 지역명을 쓰고, "예시 시나리오" 표지와 고지 문안을 항상 함께 보인다.
