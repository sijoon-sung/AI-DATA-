## 1. 맞춰야 할 목표

| 구분 | 내용 | 성격 |
|---|---|---|
| 규정 | 근거 제시(회의록명, 회의일자, 원문 구간), 인과 단정 금지, 기간 밖 정보 금지, 상용 API 금지, 라이선스, 개인정보 | 통과해야 하는 조건 |
| J1 (문제별 심사 기준) | 핵심 이슈 도출, 최초 등장 시점, 다른 지방의회로의 전파 경로를 얼마나 정밀하게 추적했는가 | 주 목표 |
| J2 (문제별 심사 기준) | 핵심 이슈의 파급 흐름 예측이 논리적으로 타당한가 | 주 목표 |

## 2. 모든 결정에 공통인 판단 순서

1. **규정을 어기는 방법은 버린다.** 성능이 좋아도 쓰지 않는다.
2. **J1, J2에 대한 기여를 하위 문제의 지표로 잰다.** 이것이 주 기준이다.
3. **N에 대한 기여.** 지표가 같으면 연구 비교가 되는 쪽을 택하고, 남는 시간도 그쪽에 쓴다.
4. **비용과 위험.** 지표 차이가 신뢰구간 안이면 더 단순하고 싼 방법을 쓴다. 다만 비교 결과는 연구 결과로 남긴다.

**"측정으로 이겼다"의 정의:** 같은 평가셋에서 두 방법의 차이를 짝지은 부트스트랩으로 구했을 때, 95% 신뢰구간이 0을 포함하지 않는 경우다.

**기준값을 다루는 규칙:** 아래 합격선과 목표는 첫 측정 전에 정한 잠정값이다. 측정 뒤에 바꿀 수는 있지만, 바꿀 때마다 이유를 `작업기록.md`에 남긴다. 결과를 보고 목표를 슬쩍 옮기는 일을 막기 위해서다.

## 3. 심사 기준을 측정할 수 있게 풀기

### J1 "추적의 정밀도"는 세 부분으로 나뉜다

| 부분 | 정밀하다는 것의 뜻 | 재는 곳 |
|---|---|---|
| 이슈 | 같은 것은 묶고 다른 것은 나눈다 | P1 |
| 최초 등장 | 의회와 날짜가 맞고, 그 날짜를 얼마나 믿을 수 있는지 표시한다 | P3 |
| 전파 경로 | 순서가 맞고, 연결마다 근거 수준이 맞으며, 거짓 화살표가 없다 | P4 |

**원칙: 앞단은 재현율, 뒷단은 정밀도.**
- 검색(P2)에서 빠뜨린 문단은 뒤에서 되살릴 수 없다. 이른 언급 하나를 놓치면 최초 시점이 틀린다. 그래서 검색은 재현율을 먼저 본다.
- 최종 결과(P4 연결, P6 주장)에서 틀린 화살표는 시스템 전체의 신뢰를 무너뜨린다. 빠진 화살표는 "확인된 연결 없음"으로 남을 뿐이다. 그래서 연결은 정밀도를 재현율보다 2배 무겁게 보는 F0.5로 잰다.

### J2 "예측의 논리적 타당성"은 여섯 조건으로 나뉜다

1. 예측 시점 이전의 정보만 썼는가 (미래 정보 누수가 없는가)
2. 같은 논리가 과거에 맞았는가 (백테스트)
3. 확신의 정도가 실제 적중률과 맞는가 (보정)
4. 이유가 근거와 연결되는가 (요인마다 회의록 근거)
5. 이슈 유형에 맞는 논리인가 (하향 대응형과 순차 확산형에 다른 설명)
6. 인과를 단정하지 않는가 (인과 과장률)

### 결과표 한 행 점검표 (심사위원의 눈으로)

| 번호 | 점검 | 자동 점검 |
|---|---|---|
| 1 | 이슈 이름만 보고 무엇에 관한 것인지 알 수 있는가 | 아니오 |
| 2 | 최초 관측 의회와 날짜가 근거 원문과 맞고, 확실성이 표시되어 있는가 | 일부 |
| 3 | 흐름의 의회 순서가 맞고, 화살표마다 근거 수준이 있으며, 근거 없는 화살표가 없는가 | 일부 |
| 4 | 예측에 등급, 이유, 근거가 있고 인과 단정이 없는가 | 일부 |
| 5 | 모든 인용이 원문과 글자까지 같고 회의록명과 일자가 붙어 있는가 | 예 |
| 6 | 일반인의 정보가 들어 있지 않은가 | 예 |

최종 결과표는 모든 행을 자동으로 점검하고, 10행을 뽑아 사람이 1~6을 모두 점검한다.

## 4. 하위 문제

| 하위 문제 | 질문 | 주로 닿는 기준 | 연구 비교 |
|---|---|---|---|
| P0 데이터 기반 | 회의록을 원문 위치가 보존된 문단으로 | 바탕 | 아니오 (완료) |
| P1 이슈 정의와 도출 | 무엇이 하나의 이슈이고, 무엇이 핵심인가 | J1 | 아니오 |
| P2 언급 탐지 | 어떤 문단이 그 이슈를 말하는가 | J1의 바탕 | **예 (RQ1)** |
| P3 최초 관측 | 어느 의회에서 언제 처음 관측되었나 | J1 | P2의 최종 지표 |
| P4 연결과 근거 수준 | 의회 사이가 어떻게 이어졌고, 그 근거는 어느 수준인가 | J1 | **예 (RQ2)** |
| P5 확산 예측 | 아직 다루지 않은 의회 중 어디가 다음이고, 왜인가 | J2 | 기준선 비교, RQ2의 기여 측정 |
| P6 서술 생성과 검증 | 네 항목을 근거에 충실한 문장으로 | J1·J2의 표현, 규정 | **예 (RQ3)** |
| P7 제공 | 결과표, 데모, 노트북, 영상, 보고서 | 효과성, 우수성 | 아니오 |

### P1. 이슈 정의와 도출

- **입력 → 출력:** 회의록 전체 → 정책 수단 목록(이름, 대표 조례, 다른 표기)과 상위 주제, 핵심 이슈 순위
- **어려운 점:** 이슈의 넓이, 표기가 다른 같은 이슈, 무엇을 핵심으로 볼지
- **지표:** 군집 순도(표본 50개를 사람이 점검), 같은 이슈가 둘로 나뉜 비율(표본 점검)
- **합격선 / 목표:** 순도 0.85 / 0.90
- **후보와 고르는 규칙:** 글자 정규화 / bge-m3 군집 / 군집 + LLM 이름 붙이기(대표 조례 제목을 근거로). 순도가 높은 쪽을 고르고, 같으면 단순한 쪽을 고른다.
- **핵심 이슈 선정 규칙 (공개):** 3곳 이상의 의회, 기간 중 신규 등장, 근거의 풍부함을 본다. 그리고 결과표에 하향 대응형과 순차 확산형이 함께 들어가게 한다. 둘의 구분을 결과로 보여 주기 위해서다.

### P2. 언급 탐지 (검색)

- **입력 → 출력:** 이슈 → 그 이슈를 말하는 모든 문단(점수, 원문 위치)
- **어려운 점:** 356만 문단에서 빠짐없이, 특히 이른 시점의 언급을 찾아야 한다. 흔한 단어는 오탐을 부른다.
- **지표:** 첫 언급 재현율(P3 정답의 첫 언급 문단을 찾았는가), 정밀도(표본 100개)
- **합격선 / 목표:** 첫 언급 재현율 0.85 / 0.95, 정밀도 0.85 / 0.92
- **후보와 고르는 규칙:** BM25 / bge-m3 밀집 / 하이브리드 + 재순위 / 여기에 LLM 확인 추가. 재현율 합격선을 넘는 것 가운데 정밀도가 가장 높은 것을 고른다.
- **연구 (RQ1):** 일반 RAG(유사도 상위 k)가 "최초" 질문에서 얼마나 틀리는지 보이고, 고재현율 검색과 시간순 검증이 그것을 얼마나 고치는지 잰다.

### P3. 최초 관측

- **입력 → 출력:** 이슈 × 의회 → 최초 언급일, 확인된 최초 관측일, 관측 구간(직전 무언급 회의), 신규성 표시(관찰 준비 기간에 이미 있었는가)
- **어려운 점:** 오탐 하나가 "최초"가 된다. 회기 일정 때문에 날짜가 성기다. 데이터 시작점 이전의 논의가 있다.
- **지표:** 월 단위 일치율, 날짜 오차 중앙값, 신규성 표시 정확도(정답 G3 기준)
- **합격선 / 목표:** 월 단위 일치율 0.70 / 0.85
- **후보와 고르는 규칙:** 최초 언급 그대로 / 확인 규칙(재언급, 점수 기준) / 여기에 LLM 검증 추가. 일치율로 고른다.
- **오류 원인 분류:** 틀린 사례마다 원인을 P2 누락, P2 오탐, P3 규칙 중 하나로 나눠 센다. 어느 단계를 고쳐야 하는지가 보인다.

### P4. 연결과 근거 수준

| 세부 | 출력 | 지표 | 합격선 / 목표 | 후보 |
|---|---|---|---|---|
| 4a 명시적 참조 추출 | (B의 문단, 참조된 의회 A, 정책, 근거 구간) | 정책 참조 F1 (G1), 근거 구간 일치 | 규칙보다 유의하게 높음 / 0.80 | 규칙 / KoELECTRA 미세조정 / LLM(근거 구간 제시) |
| 4b 공통 외부요인 | 외부 원인 단서(법령명, 지침)와 동시성 점수 | 하향 요인 F1 (G2) | 0.75 / 0.85 | 규칙 / KoELECTRA / LLM |
| 4c 선후 판정 | 확실한 선후 또는 선후 불명 | 거짓 화살표 비율 (G3) | 10% 이하 / 5% 이하 | 관측 구간 규칙 (코드, 비교 없음) |
| 4d 이슈 유형 | 하향 대응형 / 순차 확산형 / 단일 지역형 | 사람 판정과의 일치율 (G3) | 0.70 / 0.80 | 규칙 / 규칙 + 4a·4b 결과 |

- **정답 없이 하는 점검 (참조 일관성):** B가 "A는 이미 시행"이라고 말한 경우, A의 최초 관측이 실제로 그 발언보다 앞서는 비율을 잰다. 목표는 0.80이다.
- **연결 전체:** F0.5로 잰다(3절 원칙).
- **연구 (RQ2):** 규칙, 작은 미세조정 모델, LLM 근거 구간 추출을 같은 정답셋으로 비교한다.

### P5. 확산 예측

- **입력 → 출력:** (이슈, 아직 다루지 않은 의회) → 등급, 요인, 요인별 근거
- **지표:** 백테스트 AUC와 상위 3 적중률, 보정(등급별 실제 적중률, 기대 보정 오차), 요인의 근거 부착률
- **합격선 / 목표:**
  - AUC: 단순 기준선(0.71~0.73)을 신뢰구간 밖으로 넘음 / 0.78
  - 등급별 적중률이 등급 순서대로 높아질 것(필수)
  - 근거 부착률 100%(필수)
- **후보와 고르는 규칙:**
  - 모형: 단순 기준 / 로지스틱 / LightGBM.
  - 변수 묶음: 기본 / 기본 + 4a 참조와 전조 신호 / 여기에 유형 추가.
  - AUC가 신뢰구간 안에서 같으면 로지스틱을 쓴다. 설명하기 쉽기 때문이다.
- **RQ2의 기여 측정:** 4a의 결과를 변수로 넣었을 때와 뺐을 때의 AUC 차이. 근거 추출의 품질이 J2의 숫자로 이어지는지 보여 준다.

### P6. 서술 생성과 검증

- **입력 → 출력:** 이슈별 근거 묶음 → 네 항목의 서술과 인용
- **지표:**
  - 인용 원문 일치: 필수 100%
  - 사건표와의 사실 일치(날짜, 의회, 순서): 검증 뒤 필수 100%
  - 근거 없는 주장 비율
  - 인과 과장률
  - 읽기 좋은 정도(사람 평가 1~5)
- **합격선 / 목표:** 근거 없는 주장 5% 이하 / 2% 이하, 인과 과장 2% 이하 / 0%
- **후보와 고르는 규칙:** 템플릿 / 일반 RAG 생성 / 근거 수준 조건부 생성 + 검증. 필수 조건을 통과한 것 중 근거 없는 주장이 가장 적은 것을 고르고, 같으면 읽기 좋은 쪽을 고른다.
- **연구 (RQ3):** "인과 단정 금지"를 인과 과장률이라는 지표로 바꿔 재고 줄인다. 근거가 모자라면 "확인 불가"로 답하는 장치도 여기에 포함한다.

### P7. 제공

- **출력:** 결과표, 데모, 노트북, 데모영상, 기술보고서
- **지표:** 제출 전 확인 목록 7개 모두 충족, 새 환경에서 처음부터 실행한 결과표가 같음, 데모로 세 사용자(국회·보좌진, 지방의원, 시민)의 대표 질문에 답할 수 있음
- **결과표 점검:** 3절의 한 행 점검표

## 5. 의존 관계와 단계별 평가

```
P1 이슈 ─▶ P2 언급 탐지 ─▶ P3 최초 관측 ─▶ P4c 선후 ─┐
                │                                     ├─▶ P4d 유형 ─▶ P5 예측 ─▶ P6 서술 ─▶ P7 제공
                └─▶ P4a 참조 추출, P4b 외부요인 ─────┘                 ▲
                         └──────────── 전조 신호 변수 ─────────────────┘
```

- P2의 재현율이 뒤의 모든 단계를 제약한다. 그래서 P2를 가장 먼저 측정 가능한 상태로 만든다.
- 각 단계를 따로 평가한다. 최종 결과가 틀렸을 때 어느 단계에서 틀렸는지 알 수 있어야 고칠 곳이 정해진다.

## 6. 평가 데이터: 한 번 만들어 여러 곳에 쓰기

| 정답셋 | 내용 | 규모 | 쓰는 곳 |
|---|---|---|---|
| G1 | 타 지역 언급의 성격(ref) | 300건 | P4a, RQ2 |
| G2 | 하향 요인(topdown) | 200건 | P4b |
| G3 | 이슈 20~30개를 사람이 직접 추적. 의회별 최초 언급 문단, 명시적 참조, 이슈 유형을 함께 기록 | 이슈 20~30개 | P2 재현율, P3, P4c, P4d, RQ1 |
| G4 | 군집 순도 표본 | 50개 | P1 |
| G5 | 언급 정밀도 표본 | 100개 | P2 |
| G6 | 생성문 원자 주장 판정. 어느 방식이 만든 문장인지 가린 채로 | 300개 | P6, RQ3 |

- P5는 사람 정답이 필요 없다. 정답이 데이터 안에 있다(실제로 등장했는가).
- G3를 만들 때 최초 언급, 참조, 유형을 한 번에 기록하면 다섯 곳에 쓸 수 있다. 가장 효율이 높은 정답셋이다.
- 각 정답셋은 방법을 고르는 데 쓰는 개발용과 최종 보고에 쓰는 평가용으로 나누고, 평가용은 마지막에만 본다.

## 7. 연구 비교의 위치

| 연구 질문 | 하위 문제 | 비교 | 닿는 기준 |
|---|---|---|---|
| RQ1 시간 인지 검색 | P2, P3 | 일반 RAG vs 고재현율 검색 + 시간순 검증 | J1 최초 등장, 경로 |
| RQ2 근거 구간 추출 | P4a, P4b, P5 | 규칙 vs 미세조정 소형 모델 vs LLM | J1 경로의 근거 수준, J2 예측 변수 |
| RQ3 근거 수준 조건부 생성과 검증 | P6 | 템플릿 vs 일반 RAG vs 조건부 생성 + 검증 | J2 논리적 타당성, 규정 |

연구 비교가 없는 하위 문제(P1, P4c, P4d, P7)는 방법 하나만 만든다. 그 대신 지표로 합격선을 넘었는지는 확인한다.

## 8. 아직 정하지 않은 것

- 결과표에 올릴 이슈 수(30~50개 안)
- 예측 기간 단위(6개월 또는 분기)
- 위 합격선과 목표의 수치. 잠정값이며, 첫 측정 뒤 조정할 수 있다(2절 규칙).
- 결과표 형식: 대회 공식 예시 표가 있는지 확인이 필요하다.
